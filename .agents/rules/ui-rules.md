# UI / Általános Design Szabályok

1. **Szigorú Padding Szabály**: Egyetlen widget belső tartalma sem lóghat túl vagy csúszhat rá a widgeteket határoló belső paddingre. Minden tartalomnak, gombnak és elrendezésnek (pl. flex-box shrink, min-height: 0, overflow: hidden beállításokkal) rugalmasan idomulnia kell a rendelkezésre álló helyhez, hogy kisebb méretezés esetén se lógjanak ki a dobozról vagy takarják ki a paddinget.
